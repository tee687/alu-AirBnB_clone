# AirBnB Clone - The Console

## Description of the Project
The AirBnB Clone project is the first step toward building a full-featured web application clone of AirBnB. This initial stage implements a backend command interpreter (console) built with Python's `cmd` module. The console allows users to manage the storage and lifecycle of AirBnB objects (Users, Places, States, Cities, Amenities, and Reviews) through JSON serialization/deserialization.

---

## Command Interpreter

The command interpreter acts as a shell dedicated to managing the application's storage engine and data models.
